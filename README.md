# Задание по программированию с углублением в тему

Это задание продвинутого уровня. Оно предполагает изучение дополнительных материалов, которые помогут вам найти решение. Прочитайте предложенные источники, разберитесь с новой информацией и попробуйте применить её на практике.

1) Создайте html-файл (напр. "index.html"), в тексте которого напишите:

```html
<!DOCTYPE html>

<html lang="ru">
<head>

<meta charset="UTF-8">

<title> Пример простой страницы html</title>
</head>

<body>

Я НЕРЕАЛЬНО КРУТ И МОЙ РЕСПЕКТ БЕЗ МЕРЫ :)
</body>

</html>
```
                  
2) Создайте приложение FastAPI, которое принимает GET-запрос к дефолтной конечной точке (маршруту, адресу странички) `/` и возвращает html-страницу.

3) Сохраните файл и запустите приложение с помощью `uvicorn`: 

uvicorn main:app --reload

Откройте 'http://localhost:8000'в вашем веб-браузере. 

Для выполнения задания можно прочитать про возможность FastAPI "FileResponse". Сделать это можно например тут:

​​​https://metanit.com/python/fastapi/1.4.php

# Запуск приложения

1. **Клонирование репозитория**

`git clone git@github.com:XDKAY/FastAPICourseLesson2.git`

2. **Перейти в проект**

`cd FastAPICourseLesson2`

3. **Создание виртуального окружения**

`uv venv`

4. **Установка зависимостей**

`uv sync`

5. **Запуск проекта**

`uvicorn main:app --reload`

Переходим на http://127.0.0.1:8000/
